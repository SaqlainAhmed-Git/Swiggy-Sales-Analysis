# Swiggy Sales Analysis | Excel Dashboard

## Project Overview
This project focuses on analyzing Swiggy sales and order data using Microsoft Excel. The objective is to understand sales performance, customer ratings, food preferences, and geographical trends through an interactive dashboard.

## Business Objectives
- Evaluate overall sales performance.
- Understand monthly and quarterly sales trends.
- Compare Veg and Non-Veg sales.
- Identify sales patterns across different weekdays.
- Analyze state-wise sales performance.
- Monitor order volume and customer ratings.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Data Analysis

## Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Average Order Value
- Average Customer Rating
- Total Ratings

## Analysis Performed
1. Monthly Sales Analysis
2. Quarterly Sales Analysis
3. Food Type Analysis (Veg vs Non-Veg)
4. Daily Sales Analysis
5. State-wise Sales Analysis

## Project Files
- Excel workbook containing raw data,Required Images

## Conclusion
This analysis provides an overview of Swiggy's sales performance and order trends. The dashboard helps explore business performance across different time periods, food categories and geographical locations.
